Semantic HTML, made presentable.

Purus CSS is a class-light, HTML-first foundation for sites that value clarity, accessibility, and a small public API.

Get started View on GitHub

Principles

HTML first

Native elements receive polished defaults without requiring presentational classes.

Eleven classes

A deliberately small API covers reusable layouts and components without utilities.

Accessible defaults

Clear focus, contrast, validation, motion, and forced-color behavior are built in.
