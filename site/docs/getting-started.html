Getting started

Install the dependency or use a version-pinned CDN URL. Purus CSS ships no consumer JavaScript.

npm

npm install purus-css@1.0.0
@import "purus-css";

CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/purus-css@1.0.0/dist/purus.min.css">

Quick start

Write semantic HTML first. Add .container to constrain a page and layout classes only where content requires them.

Reset notice: version 1.0.0 replaces every pre-release selector and file. There is no compatibility layer.
