Token reference

Override semantic tokens after importing Purus CSS. Preserve their meaning across themes.

Supported token groups
Group Tokens
Color --color-bg, --color-surface, --color-surface-muted, --color-text, --color-muted, --color-border, --color-link, --color-focus, --color-error
Type --font-sans, --font-mono, --text-sm, --text-lg, --text-xl
Space --space-1 through --space-7, --gutter
Shape --radius, --radius-full, --shadow, --focus-ring
Layout --measure, --container, --stack-space, --cluster-space, --grid-min, --sidebar-width, --sidebar-gap

Themes

The default follows the system preference. Set data-theme="light" or data-theme="dark" on html for an explicit theme.
