Accessibility

Purus CSS provides visible keyboard focus, WCAG AA color contrast, reduced-motion behavior, forced-colors support, clear disabled states, and restrained validation styling.

Your responsibility

Use correct landmarks, heading order, labels, alternative text, and native controls. CSS cannot repair incorrect HTML semantics.

Never remove focus indicators. Use .visually-hidden for skip links and labels that must remain available to assistive technology.
