Class reference

These eleven classes are the entire supported class API. Set component-local custom properties inline in your own stylesheet when a layout needs different values.

.container
Centered page width with responsive gutters.
.prose
Readable measure and long-form rhythm.
.stack
Vertical flow using --stack-space.
.cluster
Wrapping row using --cluster-space.
.grid
Intrinsic auto-fit grid using --grid-min.
.sidebar
Collapsing two-column layout using --sidebar-width and --sidebar-gap.
.card
Bordered reusable surface.
.button
Native-button appearance for links.
.badge
Compact inline label.
.callout
Emphasized semantic aside.
.visually-hidden
Screen-reader-only content that becomes visible on focus.
