# Atkinson Hyperlegible Next

The Purus CSS website uses Atkinson Hyperlegible Next, designed by Applied
Design Works for the Braille Institute of America.

The normal and italic variable WOFF2 files are sourced from the
[official Atkinson Hyperlegible Next repository](https://github.com/googlefonts/atkinson-hyperlegible-next).
They are licensed under the SIL Open Font License 1.1; see `OFL.txt`.
